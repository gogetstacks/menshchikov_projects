# Описание проекта "Рынок заведений общественного питания Москвы"

## Данные
Датасет с заведениями общественного питания Москвы, составленный на основе данных сервисов Яндекс Карты и Яндекс Бизнес.
## Описание проекта

В наши дни процесс открытия любого бизнеса не может обойтись без работы аналитиков. Необходимо помочь инвесторам из фонда «Shut Up and Take My Money» открыть заведение общественного питания в Москве. С этой целью, изучим датасет с заведениями общественного питания Москвы, составленный на основе данных сервисов Яндекс Карты и Яндекс Бизнес на лето 2022 года. Подготовим исследование рынка Москвы, найдём интересные особенности и оформим полученные результаты, которые в будущем помогут в выборе подходящего инвесторам места.

## Цель исследования

На основе представленного датасета найдём закономерности на рынке общественного питания в Москве и выберем наиболее удачные локации для открытия нового бизнеса. Изучим представленные данные более чем о 8000 заведений общественного питания в Москве, с помощью инструментов геоаналитики изучим расположение заведений, информацию о среднем чеке и стоиомости чашки капучино, чтобы применить это к проекту по открытию кофейни.

## Ход исследования:

1. Подготовка данных: загрузка и изучение общей информации из представленных датасетов.
2. Предобработка данных: создание дополнительных столбцов, проверка пропусков, типов данных и дубликатов.
3. Анализ данных: ответы на вопросы.
4. Детализация исследования: открытие кофейни.
5. Презентация результатов исследования.

С помощью данного исследования мы пытаемся выявить наиболее удачные районы для открытия нового бизнеса в сфере общественного питания.
