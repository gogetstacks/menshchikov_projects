# Описание проекта "Интернет магазин"

## Данные
- датасет с данными о постраничном посещении сайта пользователями
## Описание проекта

В наши дни покупки в интеренете занимают большую долю всех совершаемых покупок в мире. Изучим воронку продаж продуктового интернет магазина. Узнаем, как пользователи доходят до покупки. Сколько пользователей доходит до покупки, а сколько — «застревает» на предыдущих шагах, на каких именно. Вместе с дизайнерами и менеджерами примем решение о влиянии нового шрифта в мобильном приложении на пользовательский опыт по результатам A/A/B-теста.

## Цель исследования

На основе A/A/B-тестирования проверить влияние нового шрифта на пользовательский опыт и подготовить рекомендации для дизайнеров и маркетологов.

## Ход исследования:

1. Подготовка данных: загрузка и изучение общей информации из представленных датасетов.
2. Предобработка данных: замена названий столбцов, проверка пропусков, типов данных и дубликатов.
3. Изучение и проверка данных: ответы на вопросы.
4. Изучение воронки событий: определение частоты встречаемости событий, сортировк событий по числу пользователей.
5. Анализ A/A/B-теста: построение графиков, расчёт статистической значимости, принятие решения по результатам.

С помощью данного исследования мы пытаемся принять решение об успешности (или провале) теста, определить, стоит ли его продолжать.
