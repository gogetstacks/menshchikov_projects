# Описание проекта "Анализ бизнес показателей"

## Данные

## Описание проекта

Развлекательное приложения Procrastinate Pro+ столкунлось с проблемой - несмотря на огромные вложения в его рекламу, последние несколько месяцев компания терпит убытки. На основе данных о пользователях, привлечённых с 1 мая по 27 октября 2019 года, попробуем разобраться в причинах и помочь компании выйти в плюс.

## Цель исследования

Выявить причины убытков в рекламной компании приложения Procrastinate Pro+ и найти методы, которые помогут выйти в плюс.

## Ход исследования:

1. Подготовка данных: загрузка и изучение общей информации из представленных датасетов.
2. Предобработка данных: поиск и обработка пропущенных значений, корректировка типа данных, дубликатов и других аномалий.
3. Написание функции для расчёта и анализа LTV, ROI, удержания и конверсии.
4. Исследовательский анализ данных: составление профилей пользователей.
5. Маркетинг: подсчёт общей суммы расходов, нахождение САС.
6. Оценка окупаемости рекламы: анализ окупаемости рекламы с помощью графиков.
7. Общий вывод: Резюмирование полученных результатов, формулировка ключевых выводов и рекомендаций.

С помощью данного исследования необходимо определить причины убытков компании при проведении рекламы приложения и предложить методы улучшения окупаемости.
