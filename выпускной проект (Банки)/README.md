# Описание проекта "Выпускной проект (Банки)"

## Данные
- датасет данных о клиентах "Метанпромбанка"
## Описание проекта

В наши дни без работы аналитиков не может функционировать ни одна сфера услуг, в том числе банковская. Изучим данные, предоставленные "Метанпромбанком". Узнаем, какие клиенты склонны к уходу из банков. Составим портреты типичных отточных и лояльных клиентов, поделим всех клиентов на сегменты а также выдвинем и проверим статистические гипотезы. На основе исследования составим рекомендации для менеджеров по каждому сегменту клиентов.

## Цель исследования

На основе исследовательского анализа и проверки статистических гипотез выделим сегменты клиентов и проанализируем вероятность их оттока, составим рекомендации для менеджера проекта.

## Ход исследования:

1. Подготовка данных: загрузка и изучение общей информации из представленных датасетов;
2. Предобработка данных: замена названий столбцов, проверка пропусков, типов данных и дубликатов;
3. Исследовательский анализ:
    * сравнение портретов лояльного и отточного клиентов,
    * распределение непрерывных величин,
    * корреляционный анализ;
4. Проверка статистических гипотез;
5. Сегментация на основе стратегических показателей.

С помощью данного исследования мы пытаемся выделить потенциально отточные сегменты клиентов и сформировать рекомендации по каждому из них.
